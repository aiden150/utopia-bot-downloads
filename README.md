# Utopia Bot

One-page English download site for Utopia Bot. Mystery eggs respond to clicks with a shake and speech bubble.

Installers are published as GitHub Release assets; they are not committed to Git.

## Local preview

Run `python3 -m http.server 4188` and open http://localhost:4188.

## Deployment

Static website on Vercel, no build step.
